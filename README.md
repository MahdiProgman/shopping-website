## 🏃 How to Run?
clone it and go to the folder.

first of all, rename `.env.exmaple` to `.env`.

second, rename `config.exmaple.json` to `config.json` in `config` folder.

you can use random string for secret variables in `.env`.

and finally run this:
```
docker compose up --build -d
```

now you can see the bad guy in:
```
localhost:8080
```
